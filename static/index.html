THREE MINUTES TO THE CORE

Follow a conclusion as it changes.

  1. Investigate Cedar. The receipt is missing. Notice the unknown status rather than a fabricated failure.
  2. Add the correction email. Reinvestigate. Open the receipt quote and the updated commitment.
  3. Open Versions. Compare the source sets and conclusions side by side.
  4. Open Evidence map. Exclude the correction source and rerun to see which conclusion loses support.
  5. Try Live AI + Review. With a server key configured, ask a question and request the second-pass evidence assessment.

Sample replay uses authored reports. Live AI and semantic Review require API access. Sources, versions and reviewer notes stay in this tab unless you save a case file.

Use your own API key

Your key stays in this tab's memory until cleared or reloaded. Each AI request sends it through this app's server to the selected provider. Only enter a key on a deployment you trust, using HTTPS or localhost. It is not included in case exports or saved to browser storage.
