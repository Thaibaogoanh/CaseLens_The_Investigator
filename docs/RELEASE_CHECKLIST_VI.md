# Chốt bài trước khi nộp

## Đã có trong source

- [x] Ba tình huống giả lập, bốn trạng thái báo cáo mẫu.
- [x] Live analysis và Live Q&A với key ở server.
- [x] Review claim bằng một lượt AI riêng.
- [x] Kiểm tra schema, project scope, trích dẫn và chronology.
- [x] Evidence map và nguồn chưa được trích dẫn.
- [x] Cảnh báo nội dung nguồn lặp.
- [x] Thêm hoặc loại nguồn; giữ snapshot cũ.
- [x] So sánh phiên bản.
- [x] Nhập JSON/CSV/EML text/plain.
- [x] Lưu/khôi phục case file; không tin nhãn nguồn gốc của report nhập lại.
- [x] Ghi quyết định và nhận xét của người kiểm duyệt.
- [x] Export Markdown và printable HTML.
- [x] Kiểm thử backend, DOM và trình duyệt sample.
- [x] Hướng dẫn GitHub, Docker, deploy, demo và trả lời giám khảo.

## Bắt buộc hoàn tất bằng tài khoản/môi trường của bạn

- [ ] Đọc brief chi tiết trong portal, đối chiếu yêu cầu riêng.
- [ ] Tạo API key trong tài khoản API phù hợp, cấu hình trên host.
- [ ] Chạy Live AI trên cả ba case và dữ liệu nhập mới.
- [ ] Chạy Ask và Review; mở trích dẫn để xem diễn giải.
- [ ] Chạy live stress evaluation, lưu kết quả và đọc những assertion quan trọng.
- [ ] Kiểm tra Git không chứa .env, token hoặc dữ liệu thật.
- [ ] Push repository public, kiểm tra Actions thật sự chạy đạt.
- [ ] Deploy app; mở URL HTTPS từ cửa sổ mới.
- [ ] Kiểm tra gói host và hạn mức API đủ cho thời gian chấm.
- [ ] Điền URL app thật vào README và nội dung submission.
- [ ] Điền cả repo và live app vào portal, bấm submit và xác nhận trạng thái.
- [ ] Chuẩn bị video và một lượt demo tiếng Anh có thời gian rõ ràng.

## Khi nào chưa nên tuyên bố sẵn sàng nộp?

- Chỉ sample hoạt động nhưng chưa gọi model thật.
- Live URL chỉ mở được trên máy bạn hoặc không có backend.
- Repo chỉ chứa ZIP thay vì source.
- Bộ eval có lỗi quan trọng chưa hiểu nguyên nhân.
- Chưa đối chiếu yêu cầu riêng trong portal.
