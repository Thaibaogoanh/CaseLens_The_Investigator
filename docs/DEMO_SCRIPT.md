# English demo — 10 minutes

0:00–1:00: “When a client escalates, the answer is scattered across tickets,
emails and chat. CaseLens reconstructs the record, keeping evidence separate
from interpretation.” Explain all demo records are fictional.

1:00–2:30: Open Cedar, investigate, show the missing receipt and unknown status.
Open a citation. “No receipt is not proof that delivery failed.”

2:30–4:00: Add the correction email, reinvestigate, open the receipt quote and
Versions. “New evidence changes the conclusion; the earlier version is retained.”
Use Sample replay if showing the authored flow; label it honestly. Show at least
one real Live AI run, with quota available, and distinguish it from replay.

4:00–5:00: Show Evidence map, exclude the correction and explain scope sensitivity.
Do not imply coverage counts measure accuracy.

5:00–6:00: Atlas commitments: delivery overdue plus prerequisite not_met.
“The target was observed missed. The prerequisite was unmet. Neither establishes
an unconditional breach or proves the cause of delay.”

6:00–7:00: Beacon: ticket Done but export still missing 200 investors. Contrast
source-attributed confirmed filter cause with unproven causal inference in Atlas.

7:00–8:00: AI Review and human note. “The reviewer checks individual claims and
the factual premises of recommended actions. It is advisory, not ground truth.”

8:00–9:00: Save case, restore, show portable handoff. API settings supports a
visitor key; key remains in tab memory and passes through this trusted server.
Do not show an actual key or put one in a recording.

9:00–10:00: Show architecture and limitations. “Local validation establishes
structure and provenance, not truth. The next production steps are authenticated
connectors, persistence and broader live evaluation.” End by opening the live
URL and public repository.

Before the demo: ensure the public service is ready, real provider quota exists,
source citations open and the saved Cedar case is available. Do not disguise
replay or a saved report as a fresh model response.
